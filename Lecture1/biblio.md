Bibliography
- Lecture on sensitivity analysis : [pdf](https://perso.math.univ-toulouse.fr/lagnoux/files/2023/01/lecture_GSA_CC.pdf)
- Shapley values
  - Definition of Shapley values : [the original paper](https://www.rand.org/content/dam/rand/pubs/papers/2021/P295.pdf)
  - The first paper where the Shapley value was first brought into variance-based sensitivity analysis : [Owen 2014](https://epubs.siam.org/doi/10.1137/130936233)
- Estimation of Shapley values
  - Estimation with random order and/or random permutations : [Song 2016](https://users.iems.northwestern.edu/~nelsonb/Publications/SongNelsonStaum.pdf)
  - The original KernelSHAP estimator : [Lundberg 2017](https://arxiv.org/pdf/1705.07874) and [github](github.com/slundberg/shap) that builds on [LIME](https://arxiv.org/abs/1602.04938)
  - Improvement of KernelSHAP : [Covert 2021][https://proceedings.mlr.press/v130/covert21a.html)
  - A survey of algorithms and a taxonomy : [Chen 2023](https://arxiv.org/abs/2207.07605v1)
